# v1 范围与里程碑

本页定义第一个可用版本的目标交付边界，不是当前功能列表。当前已有数据库、管理 API、CE WS 消息路由和模拟器，但绝大多数 v1 业务能力尚未实现。逐项状态见[实现状态](implementation-status.md)。决策理由见[决议记录](decisions.md)。

## v1 交付物

### 功能（八项）

1. **双向消息同步** — 游戏聊天 ↔ 群聊，规则管线（过滤器 → 转换器 → 模板）挂在绑定对上
2. **账号绑定管理** — 见下方状态机
3. **自定义命令** — 纯文本与图片回复，逐条配置执行身份（控制台/指定玩家）与权限回退
4. **黑白名单** — 封禁/解封联动自定义命令
5. **AI 对接** — 通用 OpenAI 兼容接口（base URL + API key + model），厂商为预置模板
6. **占位符/变量系统** — 绑定信息、玩家状态等变量查询
7. **图片模板** — 内嵌 rod 驱动控制 Chromium 子进程渲染
8. **跨服消息同步** — 多端点绑定共享规则组

### Hub 侧账号绑定状态机（六项）

- 验证码模式（游戏内获取验证码，群内输入完成绑定）
- 信任模式（群内直接输入游戏名绑定）
- 强制绑定拦截（MC 端玩家进服时调 Hub API 查询绑定状态）
- 解绑
- 退群自动解绑
- 群名片同步为游戏 ID

### 对接与工具

- **协议规范文档**：握手、鉴权、消息目录、错误码，附带 JSON Schema（MC 侧团队的开发依据）
- **CLI 参考模拟器**：模拟 mc-server 端点（玩家加入、聊天、命令结果），兼作 CI 协议一致性测试夹具
- **LiteDB 迁移链路**：C# dotnet tool 导出 JSON + Hub `import` 命令
- **OpenAPI 3.1 规范**：`/v1` 管理接口全集 + WS 事件流订阅

## v1 明确不做

| 事项 | 排期 | 原因 |
| --- | --- | --- |
| 游戏内图片 GUI 渲染 | v1.1 协调目标 | 由 MC 团队确认交付 |
| NeoForge 支持 | 待 MC 团队确认 | 本仓库不承诺外部客户端平台排期 |
| Milky、Telegram BOT 端 | v1.1 | 先做深 OneBot11 |
| Velocity / MCDR / 独立基岩版 | 后续 | 非核心闭环 |
| Web 管理页 | 后续 | 接口先行，API 全量覆盖后 UI 只是客户端 |
| 原版插件兼容 | 不计划支持 | 选择独立进程新 API |
| LiteDB 数据的 Go 原生解析 | 不计划支持 | 用 C# 导出工具替代 |

## 工程基线

- CI：GitHub Actions — 单测、sqlc 生成校验、三库矩阵集成测试（testcontainers）、协议一致性测试（模拟器）
- 分发：单静态二进制（无 CGO）+ Docker
- 日志：slog 结构化；管理员鉴权的 `/metrics` 暴露基础 HTTP 指标
- 插件 API 在 1.0 前开发版本标记实验性；1.0 发布前评审兼容边界
